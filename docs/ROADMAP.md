# Roadmap

- 0.1.1 delivered: live output, bounded memory, tool search and subprocess regression tests.
- Next 0.1.x: native GUI testing on Mint/XFCE, dependency guidance and packaged launcher.
- 0.2.0: configurable health reports, custom user maintenance timers with preview, disable and rollback.
- 0.3.0: input devices with explicit IDs, timed re-enable and tested recovery; no global disabling rules.
- 0.4.0: managed Wine prefixes on compatible local filesystems, atomic registry, executable picker, scoped lifecycle and launcher quoting tests. Preserve external game files during removal.
- 0.5.0: measured performance profiles with backups, hardware capability checks and rollback.
- 1.0.0: tested supported-distribution matrix, signed packaging, accessibility review, documentation and public-readiness review. Public visibility requires owner instruction.

Filesystem repair remains guidance-only until an offline workflow and strong mount checks are validated. No final release or public visibility change is automatic.
